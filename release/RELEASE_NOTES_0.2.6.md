# 版本更新记录

## [0.2.6] - 2026-08-30（debug）

第八个 debug 包（约 95MB）。核心变更：**补完「普通模式」与「创造模式」——Agent 预设体系 + 能力工具 GUI + Cordis 插件化创造（host-only 无审批）**，另有灵魂/身体分离、第三方思考强度、终端直跑、文件管理增强。

**新特性：**

- 🧩 **Agent 预设体系**：接入 DSH 原生 agent-presets，默认 `meow-standard` 全家桶（待办/技能/目标/规划/子代理/问答卡全套工具），用户自建预设动态扫描；PTC/极简占位待后续
- 📎 **附加模式胶囊 + 悬浮栏 + 问答卡**：聊天栏「规划/目标」附加切换；todo/子代理悬浮栏折叠一行、点击展开浮层；ask_user 与计划审批渲染为问答卡（选项/自由文本/中文按钮，回答后折叠）
- 🗂 **工作设置页 + 会话隔离**：右侧看板第 4 页签（工作区切换/添加、Agent 预设管理、角色卡）；会话按工作区 + 预设隔离，顶栏「工作区 · 预设」小字，进聊天页自动打开最近会话
- 🪄 **创造模式**：`meow-cordis` 预设播种（= 普通全量 + tool-cordis 自指工具集 + 两份中文教学技能），host-only 全程无审批；AI 可 copy-preset 复制系统预设改造自建（系统预设只读、用户预设可写）
- 💞 **灵魂/身体分离**：人设迁入 `filesDir/.agents/memory/SOUL.md`（缺则播种、永不覆盖），AI/用户可编辑、下一条消息生效；预设回归纯净组合，人设由基座经 `{{soul}}` 变量注入
- 🧠 **第三方 Provider 思考强度**：模型条目可声明思考档位（off 恒含，value=null=支持该档但不发参）+ 思考参数格式下拉（自动=按端点探测）；聊天页档位按能力动态渲染，无声明确认时闪电钮禁用
- 📈 **缓存绝对值**：调用量看板缓存环补「命中/写入 tok」，比例条改「未缓存输入」口径
- 🖥 **终端**：node / bash 可在 App 内直接运行（BASH_FUNC 导出函数通道，绕开 W^X exec 限制）
- 📁 **文件管理**：收藏抽屉（自动同步路径）、长按直复制/移动 + 目录选择器、完整绝对路径面包屑、宫格/瀑布流视图切换、多选亮起化、隐藏文件开关

**本包修复：**

- 🐛 **顶栏两行标题被裁**：M3 1.3.0 TopAppBar 与外层 height 修饰符叠加压内容区，删掉外交给默认 expandedHeight（双机实测）
- 🐛 **面包屑根段点击原地踏步**：var 闭包捕获问题
- 🔧 主题对话框内容超高可滚动；会话抽屉悬浮化

**DSH 侧**：闭包 +14 包（预设/命令/goal/问答/subagent 系 + cordis 两包）；meow-jsonrpc 扩展 presets 读写、session 命令/问答通道、灵魂变量、llm/models reasoning 元数据；fork 补丁新增 0002（预设支撑 + 会话 cwd）与 0004（创造模式两包）。

**验证状态**：普通模式 PC 冒烟 10 项全绿 + 真机验证；创造模式真机 RPC 探针通过（AI copy-preset 闭环 / define→run / 视觉诉求路由待聊天验收）；顶栏修复双机实测；第三方思考强度待真机验收。详见 `plan/plan-standard-mode.md` / `plan/plan-creative-mode.md`。
