# 版本更新记录

## [0.2.4] - 2026-08-27（debug）

第六个 debug 包（约 94MB）。核心变更：**交互体验大整理——右侧功能看板锚定拖拽抽屉 + 底部导航美化 + 会话抽屉多选/长按管理 + 文件编辑跨 tab 状态保持**。

**新特性：**

- 🎛️ **右侧功能看板改为锚定拖拽抽屉**：支持跟手拖动 + 半拉 settle（复刻左抽屉手感），拖动更顺滑可控
- ✨ **聊天页右侧看板美化**：模式切换改左侧竖向图标页签（选中填充 / 未选中描边）+ 毛玻璃融合相切圆角 + 凸起平滑滑动动画 + 振动反馈，移除 ⋮ 下拉菜单，抽屉拉宽至 95%
- 🧭 **底部导航栏美化**：半透明背景 + 上缘分隔线 + 选中填充 / 描边图标切换 + 文字选中才显示；聊天页底图全屏、缩放跟随输入框，IME 实时驱动动画
- 📑 **会话抽屉长按菜单**：长按会话可重命名 / 删除，顶栏标题点击也可直接重命名
- ☑️ **会话抽屉右滑多选**：支持批量删除，同时保留左滑收回抽屉手势
- 📝 **Markdown 动态配置 JSONC 化**：默认模板 / 用户覆盖分离 + 深合并，旧 JS 配置自动迁移（设计规范见 `docs/design-dynamic-config.md`）
- 📂 **文件页 FAB 新建菜单**：一键新建文件 / 文件夹 / 导入
- 💾 **文件编辑/预览跨 tab 状态保持**：编辑模式、滚动位置、撤销栈在切换 tab 后原地恢复；HTML 预览在 `onPageFinished` 后轮询重试恢复滚动位置
- ⌨️ **聊天输入框支持输入法换行**：去掉 ImeAction.Send，回车改为换行
- 🤖 **设置页模型目录自动拉取**：DeepSeek 模型列表改为从后端 `llm/models` 拉取（+缓存 / 兜底 / 多模态徽标）

**本包修复：**

- 🐛 右侧功能看板模式切换退出后不再丢失记忆
- 🐛 关闭文件编辑器时同步清掉图片预览状态，避免残留
- 🎨 代码块文字色跟随主题
